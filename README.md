# 复习曲线 · 考研倒计时

一个只给小屏用的复习 App：录入今天学的内容，按 1 · 2 · 4 · 7 · 14 · 21 天 的曲线自动排复习，
并把 2026-12-19 考研初试 作为硬约束——排不下就整体压缩，最后一定在考前留白之前复习完。

## 它做什么

- 录入：一次性贴今天学的所有知识点（每行一条），标明「第一次学」还是「第 n 次复习」。
- 排计划：按曲线生成后续每一次复习日期，并补一次「考前总复习」。
- 倒推考试日：最后复习日 = 考试日 − 留白天数（默认 3 天，即 12 月 16 日）；之后的 12/17–12/18 只做轻量回顾。
- 动态调整：
  - 打卡「完全掌握」→ 按原计划继续；
  - 「有印象但不熟」→ 今天补强，明天再测一次，后续顺延；
  - 「基本遗忘」→ 从今天重新学，按短周期重排；
  - 逾期 → 一键顺延（逾期那次放今天，剩余日期重排）；
  - 改考试日 / 留白天数 / 曲线 → 自动重排受影响的计划。
- 临近考试：可用天数不够时按比例压缩，最长一天一次；实在放不下就砍掉靠后的次数。
- 数据：全部存在本机 localStorage，不联网、不上传；支持导出 / 导入 JSON 备份。

## 开发

    node --test test/scheduler.test.mjs   # 13 条引擎用例
    node serve.mjs                        # http://localhost:8787/

## 装到手机

1. 手机与电脑连同一网络，浏览器打开 http://<电脑局域网 IP>:8787/ （或部署后的 HTTPS 地址）。
2. 浏览器菜单 →「添加到主屏幕 / 安装应用」。
3. 之后从桌面图标直接打开，全屏、离线可用。

注意：离线缓存（Service Worker）只在 HTTPS 或 localhost 下生效。用局域网 IP 打开只能在线使用，
想让 App 断网也能打卡，需要 HTTPS 部署（例如 GitHub Pages）。

## 曲线规则（与 ChatGPT 里定下的一致）

- 首次学习：第 0 天
- 复习 1–6：第 1、2、4、7、14、21 天
- 考前总复习：考试日 − 留白天数（12 月 16 日）
- 轻量回顾：留白期（12 月 17–18 日）

「今天第 n 次复习」时，从第 n 级梯子往后续排：例如 n=3（11 月 24 日），
后续是 11/27、12/4、12/11，再 12/16 总复习。
